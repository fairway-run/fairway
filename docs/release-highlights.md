  render redacted local evidence artifacts, export provenance reports and hash
  manifests, and link release attestations without storing raw prompts,
  transcripts, tool bodies, generated content, or secrets.

  grouped-review, and prototype-first profiles support faster evidence-led

  rehearsal packets, reusable task recipes, owner rough-edge queues,
  process-overhead reports, UX media evidence summaries, and cross-project
